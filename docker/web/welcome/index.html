English

The port selects the PHP version and the path selects the project. No subdomains or hosts file changes are required.

Example: http://localhost:8501/ci-php runs the ci-php project with PHP 5.6 through Nginx.

To start Nginx and PHP 5.6: docker compose --profile web --profile php56 up -d.

Place source code inside the folder configured in PROJECTS_ROOT.
